# hayama-ingest 設計メモ

## 背景
沼津版（`seiichi3141/numazugikai` の `numazu-ingest`）にならい、
葉山町議会の公開情報から会期・議案を取り込むパッケージを作る。
seed直書きの創作データから実データへ置き換えるのが目的。

## データ源
- 町サイト「審議議案等の一覧と審議結果」年別index（例: 令和7年 `gikai/2_1/r2_5/index.html`）
  - 会期リンク（令和7年は5会期: 第1回定例会・第2回定例会招集会議・6月/9月/12月定例会議）
- 町サイトの会期別ページの表（議案番号・件名・付託先委員会・結果・議案PDF・議員別賛否PDF）
- 議会中継（hayama-gikai.gijiroku.com）の会期日程ページ（Shift_JIS）
  - 会期日付は町サイトに無いため、KaigiID走査（30〜70）で日程を取得する

## 使い方
```bash
pnpm --filter @mirai-gikai/topic-analysis-worker run ingest --target=sessions --era-year=7
pnpm --filter @mirai-gikai/topic-analysis-worker run ingest --target=bills --era-year=7 --month=6
pnpm --filter @mirai-gikai/topic-analysis-worker run ingest --target=all --era-year=7
```

## 仕様メモ
- slug は `hayama-r{元号年}-{回}-{月|shoshu|extra}`（例: `hayama-r7-2-06`）
- 議案名は「第20号 ○○」のように番号付きで保存する（bills に番号カラムが無いため）
- 結果→status: 可決・同意・承認・認定・採択・趣旨了承→enacted、否決・不採択→rejected、結果なし→委員会付託ありなら in_originating_house、無ければ introduced
- originating_house は一院制のため HR で統一する（表示ラベルの修正は別途）
- 日程が見つからない会期はスキップする（start/end が NOT NULL のため）
- 取込は直列＋間隔空け（相手サーバー配慮）。ingestion_runs のような実行記録テーブルは作っていない

## 対象外（フォローアップ）
- 議案PDF本文の取込（bill_contents の生成）
- 議員別賛否PDFの取込（voting-results 的な表示とセット）
- 議員名簿・会議録検索の取込
- seed創作データの実データへの置換え
